### Bragg's Law

$$n \lambda = 2d_{hkl}sin \theta$$

This formula determines $d_{hkl}$ by receiving constructive wave where the difference in distance between two waves is the times of $d_{hkl}$.

$$d_{hkl} = \frac{a}{\sqrt{h^2 + k^2 + l^2}}$$

Shows the distance from point $(0, 0, 0)$ to plane $hx + ky + lz = a$
